# Job Description: Data Analyst at Enterprise Analytics
- Date: 2026-09-29


Role: Data Analyst
Company: Enterprise Analytics
Key Responsibilities:
- Design, develop, and maintain high-impact Power BI dashboards and interactive reports for executive stakeholders.
- Write advanced SQL queries, Joins, CTEs, and Window Functions to extract, transform, and aggregate data across databases.
- Utilize DAX and Power Query for calculated measures, data modeling (star schema), and automated data transformation.
- Build Python scripts using Pandas and NumPy for exploratory data analysis (EDA), data cleaning, and reporting automation.
- Partner with cross-functional business stakeholders to define KPIs, measure SLA compliance, and translate business challenges into data-driven insights.
- Ensure high data quality assurance, accuracy, and operational integrity across user and reporting records.
